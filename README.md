# BANTUIN.ID

Web platform modern untuk layanan bantuan akademik dan IT support mahasiswa berbasis Next.js dan Supabase.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Actions)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Database & Auth**: [Supabase](https://supabase.com/) (PostgreSQL & Supabase SSR)
- **Validation**: [Zod](https://zod.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Prerequisites
- Node.js 20+
- Package Manager: `pnpm` (disarankan) atau `npm`

### 2. Installation
```bash
# Clone repository
git clone https://github.com/Fannandzaki/bantuiin.id.git
cd bantuiin.id

# Install dependencies
pnpm install
```

### 3. Environment Variables
Duplikasi file template environment dan isi dengan kredensial proyek Supabase Anda:
```bash
cp .env.example .env.local
```

### 4. Run Development Server
```bash
pnpm dev
```
Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

---

## 📜 Scripts

- `pnpm dev` - Menjalankan development server lokal
- `pnpm build` - Menjalankan production build
- `pnpm start` - Menjalankan server hasil build production
- `pnpm lint` - Melakukan pengecekan kode dengan ESLint
